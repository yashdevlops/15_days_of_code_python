# What is Programming :
Programming is the process of writing instructions that tell a computer how to perform specific tasks, especially those that are complex or time-consuming for humans. Python is a high-level, interpreted programming language known for its simplicity and readability. Created in 1989, it supports multiple programming paradigms and has a rich ecosystem of libraries. Python is widely used in fields such as data analysis, visualization, artificial intelligence, web development, and automation, making it a powerful and versatile choice for developers.
# Modules and Pip :
A module in Python is a reusable code library that allows you to use functions and features written by others. There are two types of modules: built-in modules, which come pre-installed with Python, and external modules, which are developed by third parties and can be installed using package managers like pip or conda. The pip command is commonly used to install external modules, for example, pip install pandas. Once installed, modules can be used in your program with the import statement, such as importing pandas to read and work with data files.

# Comments, Escape sequence & Print in Python:
In this section, we cover comments, escape sequences, and the basics of the print statement in Python. Comments are used to explain code or temporarily disable parts of it during testing. Python supports single-line comments using # and multi-line comments using either multiple # lines or triple-quoted strings.
Escape sequence characters allow us to include special characters in strings that cannot be written directly, such as quotes or new lines. These are created using a backslash (\) followed by a specific character.
The print() function is used to display output in Python and supports multiple optional parameters. It can print multiple objects, customize separators between them, and control how the output ends. These features make it flexible for formatting output as needed.

# Variables and data types :
A variable is a container used to store data in memory. It acts as a placeholder where values can be assigned and accessed later. In Python, variables are created simply by assigning a value, without needing to declare their type explicitly.

A data type defines the kind of value a variable holds, which helps Python perform operations correctly. You can check the type of a variable using the type() function.

Python provides several built-in data types, including numeric types (int, float, complex), text type (string), boolean type (True or False), sequence types like lists (mutable) and tuples (immutable), and mapping type like dictionaries, which store data in key-value pairs.
