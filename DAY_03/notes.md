## 🔀 Match-Case Statement (Python)

Python provides a `match-case` statement (similar to switch-case in other languages) to handle multiple conditions in a cleaner way than if-else.

It compares a variable against different patterns and executes the matching case.
🧩 Structure:
- `match` → the variable to check  
- `case` → different conditions (patterns)  
- Executes the block where the match is found  
💡 Key Idea:
The value is checked against each case until a match is found.
